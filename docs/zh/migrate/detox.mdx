## 迁移配置

<Note>按[移动端指南](/mobile)配置测试目标，按[快速开始](/quickstart)配置模型。逐个迁移测试文件时，两个运行器可以使用同一个模拟器。</Note>

| Detox（`.detoxrc.js`） | e2e |
| --- | --- |
| `apps.<name>.binaryPath`、`bundleId` | 测试目标上的 `app: { appPath, bundleId }` |
| `devices.<name>.device.type` | `mobile({ device: 'iPhone 17' })` |
| `configurations` | `targets`，每个平台一个引擎 |
| Jest `maxWorkers` | `workers`，每台设备一个工作进程 |
| `apps.<name>.launchArgs` | 测试目标上的 `app.launchArguments`，为每个平台提供字符串列表 |
| `launchApp({ permissions })` | 测试目标上的 `app.permissions`：`grant`、`deny`、`reset` 分别对应 `YES`、`NO`、`unset`。更多名称[已计划支持](#planned) |

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { mobile } from '@e2e-dev/mobile';

export default {
  targets: [
    {
      name: 'ios',
      engine: mobile({ platform: 'ios' }),
      app: {
        bundleId: 'com.example.app',
        appPath: 'ios/build/MyApp.app',
        launchArguments: ['-mockServer', 'http://localhost:9001'],
      },
    },
    {
      name: 'android',
      engine: mobile({ platform: 'android' }),
      app: {
        bundleId: 'com.example.app',
        appPath: 'android/app/build/outputs/apk/debug/app-debug.apk',
        launchArguments: ['--es', 'mockServer', 'http://localhost:9001'],
      },
    },
  ],
  workers: 1,
} satisfies E2EConfig;
```

## 改写一个测试文件

应用不会自动启动，因此 e2e 测试以 `app.open()` 开始。密码来自[配置的凭据](/authentication)。

```js title="Detox"
describe('login', () => {
  beforeAll(async () => { await device.launchApp({ newInstance: true }); });

  it('shows the home screen', async () => {
    await element(by.id('email')).typeText('ada@example.test');
    await element(by.id('password')).typeText('hunter2');
    await element(by.text('Sign in')).tap();
    await waitFor(element(by.id('home'))).toBeVisible().withTimeout(10000);
    await expect(element(by.text('Welcome, Ada'))).toBeVisible();
  });
});
```

```ts title="e2e"
import { test } from '@e2e-dev/mobile';
import { expect, credentials } from 'e2e';

test('shows the home screen', async ({ agent, app, screen }) => {
  await app.open();
  const ada = credentials.user('ada');
  await agent.act('sign in as {username}', { params: { username: ada.username, password: ada.password } });
  await expect(screen.getByTestId('home')).toBeVisible({ timeout: 10_000 });
  await expect(screen.getByText('Welcome, Ada')).toBeVisible();
});
```

## 映射每个 Detox 调用

### 匹配器和操作

| Detox | e2e |
| --- | --- |
| `by.id('x')`、`by.text('t')`、`by.label('l')` | `screen.getByTestId('x')`、`screen.getByText('t')`、`screen.getByLabel('l')` |
| `by.id('x').withAncestor(by.id('row'))` | `screen.getByTestId('row').getByTestId('x')` |
| `.atIndex(n)` | `.nth(n)` |
| `.tap()`、`.tap({ x, y })`、`.longPress()`、`.multiTap(2)` | `.tap()`、`.tap({ position: { x, y } })`、`.longPress()`、`.doubleTap()` |
| `.typeText(t)` | `.pressSequentially(t)` |
| `.replaceText(t)`、`.clearText()`、`.tapReturnKey()` | `.fill(t)`、`.clear()`、`.press('Enter')` |
| `.swipe('up', 'fast')` | `.swipe({ direction: 'down', momentum: 'fast' })`。Detox 指定手指移动方向，e2e 指定内容滚动方向 |
| `list.scroll(200, 'down')` | `list.swipe({ direction: 'down' })`，不带偏移量 |
| `waitFor(el).toBeVisible().whileElement(list).scroll(...)` | `list.scrollUntilVisible(el)`，Detox 向上滚动时使用 `{ direction: 'up' }` |

### 预期检查

| Detox | e2e |
| --- | --- |
| `waitFor(el).toBeVisible().withTimeout(ms)` | `await expect(el).toBeVisible({ timeout: ms })` |
| `.toBeVisible()`、`.toHaveText(t)` | 相同 |
| `.not.toBeVisible()` | `.toBeHidden()` |
| `.toExist()`、`.not.toExist()` | `.toBeAttached()`、`.toBeAttached({ attached: false })` |
| `.toHaveToggleValue(true)` | `.toBeChecked()` |
| `.toHaveLabel(l)` | `.toHaveAccessibleName(l)` |
| `.toHaveValue(v)` | `.toHaveValue(v)`，仅用于表单控件 |

### 设备

| Detox | e2e |
| --- | --- |
| `device.launchApp({ newInstance: true })` | `app.restart()` |
| 在 `beforeAll` 中调用 `device.launchApp()` | 在 `beforeAll` 中调用 `app.open()`，它会得到 `device`、`app` 和 `screen` |
| `device.launchApp({ newInstance: false })` | 不带 `relaunch` 的 `device.openApp(id)` |
| `device.launchApp({ launchArgs, permissions })` | `device.openApp(id, { relaunch: true, launchArguments, permissions })` |
| `device.resetAppState()` | `app.clearState()` |
| `device.launchApp({ delete: true })` | `device.installApp(path, { reinstall: true })`，然后 `app.open()` |
| `device.uninstallApp()` | `device.uninstallApp(id)`；不传 ID 时为固定的应用 |
| `device.launchApp({ url })`、`device.openURL({ url })` | `device.openLink(url)` |
| `device.terminateApp()`、`sendToHome()`、`pressBack()` | `device.closeApp()`、`home()`、`back()` |
| `device.setLocation(lat, lon)`、`setOrientation('landscape')` | `device.setLocation({ latitude, longitude })`、`setOrientation('landscape-left')` |
| `device.shake()` | `device.shake()`，在本地模拟器上 |
| `device.setBiometricEnrollment(true)` | `device.enrollBiometrics('faceid', true)` |
| `device.matchFace()`、`unmatchFace()`、`matchFinger()`、`unmatchFinger()` | `device.setBiometrics('faceid' \| 'touchid', 'match' \| 'nonmatch')` |
| `device.takeScreenshot()` | `app.screenshot('label')`，或使用 [`toHaveScreenshot`](/visual-testing) 比较 |
| `device.getPlatform()` | `platform` 测试夹具 |
| 测试名称中的 `:ios:` / `:android:` | 测试上的 `{ platforms: ['ios'] }` |

## e2e 尚未支持的功能

“已计划”表示已列入路线图，“尚未支持”表示暂无日期。“不计划支持”表示有意不提供。

### 已计划

| Detox | 当前替代方案 |
| --- | --- |
| `artifacts.plugins.log`、`--record-logs` | 在 CI 步骤中运行 `adb logcat` 或 `xcrun simctl spawn booted log stream` |
| `by.id('x').and(by.text('y'))` | `.filter({ hasText })`，或 `device.locator('id=x label="y"')` |
| `system.element(by.system.label('Allow'))` | `device.alert('accept' \| 'dismiss')`，或通过 `app.permissions` 避免显示提示 |
| `.longPressAndDrag()`、`.swipe()` 偏移量、`.multiTap(3)` | `.dragTo(target)`、`screen.swipe({ from, to })`、重复调用 `.tap()` |
| `.scrollTo('bottom')` | `list.scrollUntilVisible(lastRow)`，或对第一行使用 `{ direction: 'up' }` |
| `.tapBackspaceKey()` | 用 `.fill(t)` 填入缩短后的文本 |
| `.setDatePickerDate()`、`.setColumnToValue()`、`.adjustSliderToPosition()` | `agent.act` 目标，或在滑块上使用 `screen.swipe({ from, to })` |
| 在表单控件之外使用 `.toHaveValue(v)` | `expect(device.locator('id=x value="v"')).toBeVisible()` |
| `health`、`homekit`、`speech`、`faceid`、`userTracking` 的 `permissions`；值 `always`、`inuse`、`limited` | 点击提示中的按钮，或使用 `device.alert('accept')` |
| `device.sendUserNotification()`、`.pinch()` | [`unstable_raw`](/reference/mobile#unstable_raw) 上的 `client.apps.push()`、`client.interactions.pinch()` |
| `launchApp({ languageAndLocale })` | 在 iOS 上使用 `app.launchArguments: ['-AppleLanguages', '(fr)', '-AppleLocale', 'fr_FR']`，参阅[以其他语言运行应用](/mobile#run-the-app-in-another-language) |
| Jest `globalSetup`、`globalTeardown` | 运行前启动依赖项 |
| `device.reverseTcpPort()` | 在 CI 步骤中运行 `adb reverse` |
| 作为单个键值映射的 `launchArgs` | iOS 使用 `['-key', 'value']`，Android 使用 `['--es', 'key', 'value']` |
| `.getAttributes()` | `.textContent()`、`.inputValue()`、`.isEnabled()`、`.isVisible()`、`.isChecked()`、`.boundingBox()` |
| `device.setStatusBar()` | `xcrun simctl status_bar`。`toHaveScreenshot` 会固定状态栏 |

### 尚未支持

| Detox | 当前替代方案 |
| --- | --- |
| `.toBeVisible(50)` 以及默认的 75% | `.toBeVisible()` 检查平台标志，而非面积。比较 `.boundingBox()` |
| `web.element(by.web.cssSelector('x'))` | WebView 的无障碍文本和标签，或 `agent.act` 目标 |
| `device.resetContentAndSettings()` | `app.clearState()`，iOS 上再加 `device.clearKeychain()` |
| `device: { type, os }`、`headless`、`bootArgs` | 在 CI 步骤中创建并启动设备 |

### 不计划支持

| Detox | 替代方案 |
| --- | --- |
| `device.reloadReactNative()` | `app.restart()`。重新加载需要应用内包含 Detox 框架 |
| `device.disableSynchronization()`、`enableSynchronization()` | 删除调用。没有需要关闭的同步机制 |
| `device.setURLBlacklist()` | 删除调用。网络活动不会阻塞操作 |
| 初始化时安装、`behavior.init.reinstallApp`、`--reuse` | 在设置了 `auto: true` 的工作进程测试夹具中调用 `device.installApp()` |
| `apps.<name>.build`、`detox build` | 在 `e2e run` 前执行普通构建 |
| 按精确偏移量 `.scroll()` | `screen.swipe({ from, to })` |
| `by.type('RCTImageView')` | `device.locator('role=image')` 或 `testID` |
| Jest 报告器、Allure | `junit` 报告器或自定义报告器 |

## 有意保留的差异

- e2e 不会等待应用空闲。操作会等待，断言会重试。对于尚未出现的控件，提高 [`transition`](/reference/mobile#transition)；对于智能体操作，提高 [`settle`](/reference/mobile#settle)。
- 引擎不会自动安装任何内容。调用 `device.installApp()`。
- [定位器](/reference/screen)采用严格匹配。对多个匹配项执行操作会以 `LOCATOR_AMBIGUOUS` 失败。用 `.filter()`、`.first()` 或 `.nth()` 缩小范围。
- 设备不支持 `test.setup` 或 `{ session }`。参阅[与网页端的差异](/mobile#what-differs-from-the-web)。
