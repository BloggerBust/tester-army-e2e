e2e 信任你编写的代码，并将应用显示的所有内容视为不可信。应用内容无法向模型授予工具、凭据或更大的预算。

## 如何避免机密值进入模型

`Secret` 是一个不提供明文访问方法的句柄。模型只能看到它的名称和用途。当模型请求填入某个机密值时，运行器会检查字段并自行输入该值。

在模型的文本输入、报告、控制台输出以及 `.txt`、`.csv`、`.json`、`.html` 和 `.htm` 下载文件中，每个已知机密值都会替换为 `<secret:name>`。

## 哪些内容仍可能泄露

脱敏通过字符串匹配进行，截图则只遮盖安全字段：

- **截图，包括发送给模型的截图。** 填入普通输入框的通用机密值，或应用在安全字段之外显示的值，都会出现在图像中并传给你的模型提供方。请使用测试凭据，而非生产环境机密值。
- **视频和下载。** 视频不会遮盖任何内容，除经过脱敏的文本文件外，下载内容均按服务器提供的原样保存。如果测试输入了密码，请在共享前检查这些内容。
- **`command.log`。** 它原样保存应用的 stdout 和 stderr。避免在应用输出中包含机密值。
- **经过转换的值。** 密钥的最后四个字符或其 base64 形式会直接通过。请断言结果，而非机密值。
- **未作为机密值填入的值。** 只有已配置机密值的值会被脱敏。登录过程设置在 Cookie 中的值不会。
- **请求凭据。** `headers` 会附加到所有从应用源或你列出的源发起的请求，即使该请求由第三方页面发起，并且在重定向到任意源时仍会保留。`basicAuth` 会响应这些源的 `401`；在 WebKit 上，如果其中任一源使用默认端口或 IPv6 主机，则也会响应任意源。
- **已提交的录制记录。** 除填入机密值的操作外，缓存条目会原样保存输入值。它们没有签名，并以你的权限回放，因此请像审查测试代码一样审查它们。

[脱敏的边界](/reference/security#where-redaction-stops)列出了所有情况。

## 模型能看到什么、能做什么

模型会看到你的指令、以无障碍树表示的屏幕、脱敏后的 URL，以及测试中之前步骤的记录。当它请求截图或步骤设置了 `vision` 时，会收到经过遮盖的截图。

模型只能通过工具操作。运行器会在执行前按封闭的 schema 检查每次调用，绝不会将模型文本作为代码求值。内置工具会拒绝未声明的键，除非工具没有字段，此时它会丢弃这些键并执行；项目工具遵循自己的 `defineTool` schema。违反规则的调用（例如导航到 `file:`）会以 `POLICY_DENIED` 失败。没有源允许列表：智能体可以跟随应用进入其他网站，并在那里使用该步骤的机密值。

在 macOS 和 Windows 上，Chromium 启动时会启用操作系统沙箱，这有助于遏制智能体所到页面上的渲染进程漏洞利用。在 Linux 上需要手动开启，见 [`chromiumSandbox`](/reference/web#chromiumsandbox)。

## 哪些内容以你的权限运行

你的测试、配置、引擎、工具、报告器、存储、机密值提供方和应用命令都以你的操作系统权限运行，不受沙箱隔离。请在没有机密值或写入令牌的外部沙箱中运行不可信的拉取请求（PR）代码。

## 哪些内容会离开你的计算机

一次运行会连接模型提供方、被测应用，以及（除非你选择退出）位于 `eu.i.posthog.com` 的[遥测](/telemetry)服务。没有崩溃报告功能。终端中的 CLI 命令每天最多检查一次 `registry.npmjs.org`，寻找新版本；`e2e feedback` 会在每次报告前检查，除非使用 `--allow-outdated`；`e2e upgrade` 会读取项目列出的 e2e 包版本。Kernel、Expo Simulators、Limrun 和 smol 等集成会增加各自的目标地址，这些地址与其他连接一同列在[出站连接](/reference/security#outbound-connections)中。

## 报告漏洞

请通过 [GitHub 安全公告](https://github.com/e2e-inc/e2e/security/advisories/new)私下报告，或发送邮件至 security@e2e.com。[安全政策](https://github.com/e2e-inc/e2e/blob/main/SECURITY.md)说明了响应时间和支持的版本。
