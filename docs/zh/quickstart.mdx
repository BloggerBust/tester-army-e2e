## 使用编码智能体配置

在你的应用目录中，将以下提示词粘贴到 Claude Code、Codex、Cursor 或其他编码智能体中：

<SetupPrompt>

<Prompt description={setupPrompt} children={setupPrompt} actions={["copy", "cursor"]} />

</SetupPrompt>

智能体会安装 [e2e 技能](/coding-agents)，之后只需提供“为结账流程添加测试”这样的提示词，无需再次配置。

<Note>
使用 Node.js 24.8 或更高版本（Node.js 22 需使用 22.22.3 或更高版本）。网页端测试也可以使用 [Bun](/reference/cli#bun) 1.4.3 或更高版本。在 Windows 上，请在 WSL 中运行。移动端测试还需要安装带有 iOS 模拟器运行时的 Xcode，或带有模拟器的 Android SDK。
</Note>

## 手动配置

### 运行第一个测试

<Steps>
  <Step title="创建测试项目">
  在你的应用目录中运行：

  <CodeGroup>
  ```bash npm
  npx e2e init
  ```

  ```bash pnpm
  pnpm dlx e2e init
  ```

  ```bash bun
  bunx e2e init
  ```
  </CodeGroup>

  选择 **Web (Playwright)** 或 **Mobile (iOS/Android)**，然后选择订阅或模型提供方。不使用 AI 的测试请选择 **None**。向导会写入配置和示例测试，添加依赖项，并提供配置编码智能体的选项。已有文件会保留。

  <Tabs>
    <Tab title="网页端">
    在 `http://localhost:3000` 启动应用的开发服务器，或在 `e2e.config.ts` 中设置它的地址。你也可以[让 e2e 启动它](/web#starting-your-app)。

    <Accordion title="网页端配置和测试示例">
    这个配置使用 Vercel AI Gateway。向导会配置你选择的提供方。

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';
import { gateway } from 'ai';

export default {
  agents: { default: { model: gateway('openai/gpt-6-luna-fast') } },
  targets: [{ engine: web(), app: { url: 'http://localhost:3000' } }],
} satisfies E2EConfig;
```

```ts title="tests/example.e2e.ts"
import { test } from '@e2e-dev/web';
import { expect } from 'e2e';

test('app opens', async ({ app, browser }) => {
  await app.open('/');
  await expect(browser.locator('body')).toBeVisible();
});
```
    </Accordion>
    </Tab>
    <Tab title="移动端">
    运行 `npx e2e doctor` 检查环境。向导在 macOS 上选择 iOS，在其他系统上选择 Android。示例会打开“设置”应用。

    <Accordion title="iOS 配置和测试示例">
    这个配置使用 Vercel AI Gateway。对于 Android，向导会设置 `platform: 'android'` 和 `app: { bundleId: 'com.android.settings' }`。

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { mobile } from '@e2e-dev/mobile';
import { gateway } from 'ai';

export default {
  agents: { default: { model: gateway('openai/gpt-6-luna-fast') } },
  targets: [{ name: 'ios', engine: mobile({ platform: 'ios' }), app: { bundleId: 'Settings' } }],
  workers: 1,
} satisfies E2EConfig;
```

```ts title="tests/example.e2e.ts"
import { test } from '@e2e-dev/mobile';
import { expect } from 'e2e';

test('Settings opens', async ({ app, screen }) => {
  await app.open();
  await expect(screen.getByRole('button', 'General')).toBeVisible();
});
```
    </Accordion>

    要使用自己的应用，请参阅[移动端](/mobile)。
    </Tab>
  </Tabs>
  </Step>
  <Step title="运行示例">
  <CodeGroup>
  ```bash npm
  npx e2e run
  ```

  ```bash pnpm
  pnpm exec e2e run
  ```

  ```bash bun
  bunx e2e run
  ```
  </CodeGroup>

  e2e 会下载浏览器或启动模拟器，检查应用是否能打开，然后输出结果。示例不会调用模型，因此无需登录或提供 API 密钥。
  </Step>
</Steps>

### 添加智能体步骤

每次调用 `agent.act` 时，指定一个[原子目标](/core-concepts#goals)，然后检查结果。将示例改为你应用中的流程：

<Tabs>
  <Tab title="网页端">
```ts title="tests/agent.e2e.ts"
import { test } from '@e2e-dev/web';
import { expect } from 'e2e';

test('a visitor signs up for a trial', async ({ app, agent, screen }) => {
  await app.open('/');

  await agent.act('sign up for a free trial as {name} with email {email}', {
    params: { name: 'Ada Lovelace', email: 'ada@example.test' },
  });

  await agent.assert('the welcome screen greets Ada by name');
  await expect(screen.getByRole('status')).toContainText('trial');
});
```
  </Tab>
  <Tab title="移动端（iOS）">
```ts title="tests/agent.e2e.ts"
import { test } from '@e2e-dev/mobile';
import { expect } from 'e2e';

test('the agent opens General', async ({ agent, app, device }) => {
  await app.open();
  await agent.act('open {section} settings', { params: { section: 'General' } });

  await agent.assert('the General settings screen is showing');
  await expect(device.locator('role=navigation-bar id=General')).toBeVisible();
});
```

  `app.open()` 会重新启动应用。如果不调用它，测试会从上一个测试结束时的设备状态开始。`device.locator` 接受 [agent-device 选择器](/mobile#the-device-fixture)。
  </Tab>
</Tabs>

`params` 填充目标中的占位符。`agent.assert` 判定屏幕内容。`expect` 检查精确值。

<CodeGroup>
```bash npm
npx e2e run tests/agent.e2e.ts
```

```bash pnpm
pnpm exec e2e run tests/agent.e2e.ts
```

```bash bun
bunx e2e run tests/agent.e2e.ts
```
</CodeGroup>

如果在向导中选择了 **None**，请先[添加模型](/models)。添加 `--headed` 可以观看网页端测试的运行过程。添加 `--no-cache` 可以直接调用模型，不回放缓存的操作。

### 配置项目

`e2e.config.ts` 存放配置选项。以下是多数项目在 `init` 后会修改的选项：

| 目的 | 设置 | 参阅 |
| --- | --- | --- |
| 指向你的应用 | `app.url`，移动端使用 `app.bundleId` | [被测应用](/reference/config#the-app-under-test) |
| 运行测试时启动应用 | `app.command` | [启动应用](/web#starting-your-app) |
| 使用模型 | `agents.default.model` | [模型](/models) |
| 测试多个浏览器或设备 | 在 `targets` 中为每个浏览器或设备添加一个带 `name` 的条目 | [targets](/reference/config#targets) |
| 给测试更多时间 | `timeout`、`actionTimeout`、`assertionTimeout` | [timeout](/reference/config#timeout) |
| 重试失败的测试 | `retries`，在 CI 中为 `1` | [retries](/reference/config#retries) |
| 并行运行测试 | `workers`，在 CI 中为 `1` | [workers](/reference/config#workers) |
| 选择测试文件 | `tests` | [tests](/reference/config#tests) |
| 保留追踪记录和视频 | `trace`、`video` | [录制](/reference/config#recording) |
| 输出 JUnit 报告 | `reporters: ['list', 'junit']` | [reporters](/reference/config#reporters) |
| 登录并传入 API 密钥 | `credentials`、`secrets` | [身份验证](/authentication) |
| 在 CI 中写入回放缓存 | `cache: 'read-write'` | [缓存](/cache) |

<Accordion title="常用选项配置示例">
```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';
import { gateway } from 'ai';

const app = {
  url: process.env.APP_URL ?? 'http://localhost:3000',
  command: { executable: 'npm', args: ['run', 'dev'], reuseExisting: true },
};

export default {
  agents: { default: { model: gateway('openai/gpt-6-luna-fast') } },
  targets: [
    { name: 'chromium', engine: web({ viewport: { width: 1440, height: 900 } }), app },
    { name: 'firefox', engine: web({ browser: 'firefox' }), app },
  ],
  timeout: 180_000,
  workers: 4,
  reporters: ['list', 'junit'],
  video: 'retain-on-failure',
} satisfies E2EConfig;
```

`--target firefox` 只运行一个测试目标。使用同一个 `command` 的测试目标会共享一个服务器进程。
</Accordion>
