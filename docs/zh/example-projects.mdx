每个示例都是独立的问候应用，包含三个定位器测试和两个智能体测试。一个智能体测试根据姓名获取问候语，另一个检查姓名为空时的错误。每个示例都从 npm 安装已发布的 e2e 包。

## 运行示例

按照项目的 README 安装、构建并运行它。配置和测试与应用放在一起；原生、Flutter 和 .NET MAUI 项目将它们放在 `e2e/` 文件夹中。

定位器测试无需模型。智能体测试使用 Vercel AI Gateway，未设置 `AI_GATEWAY_API_KEY` 时会跳过。

要用 `create-next-app` 从示例创建新的 Next.js 应用，参阅 [Next.js](/frameworks/nextjs#start-a-new-app)。
