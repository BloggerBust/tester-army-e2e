e2e is an open source testing framework for web and mobile apps. Write
exact [locators](/core-concepts#locators) and
[assertions](/reference/expect#locator-matchers), natural-language
[goals](/core-concepts#goals) that an AI agent executes, or mix both in the
same test.

```ts title="tests/checkout.e2e.ts"
import { test, expect } from 'e2e';

test('a member upgrades to Pro', async ({ app, agent, screen }) => {
  await app.open('/settings/billing');

  await agent.act('upgrade the workspace to the Pro plan');
  await agent.assert('the invoice preview shows a prorated amount');

  await expect(screen.getByRole('status')).toContainText('Pro');
});
```

## Why e2e

- **Less test maintenance.** Describe the user goal instead of fragile
  chains of selectors and waits. When the UI shifts, the agent adapts so you
  fix fewer tests.
- **Fast, cheap reruns.** After an `agent.act` step passes and a later check
  confirms the result, e2e [caches the recorded actions](/cache). Future runs
  replay them with zero model calls and fall back to the agent only when the
  app changes.

## How it works

- **Targets.** Write a test once and run it across Chromium, Firefox, WebKit,
  iOS simulators, or Android emulators. The [web engine](/web) drives
  browsers with Playwright, the [mobile engine](/mobile) drives devices with
  agent-device, and you can [plug in your own engine](/writing-an-engine).
- **Agent steps.** `agent.act` completes a goal; `agent.assert`,
  `agent.waitFor`, and `agent.extract` inspect the screen. Bring your own
  [subscription](/subscriptions), [API key, or local model](/models).
- **Reports and security.** e2e [redacts registered secrets](/security) from
  model input and writes steps, screenshots, and traces to a
  [report](/debugging) for you or your coding agent to read.

## A release gate in CI

Release gates need deterministic results on every commit. You can run e2e in
CI without calling a model:

- **Locator-only tests.** Write tests with locators and `expect()` (or let
  your [coding agent](/coding-agents) write them). They don't need a model
  or API key.
- **Committed recordings.** [Commit your replay cache](/cache#commit-the-replay-cache)
  so CI replays recorded `agent.act` steps with zero model calls. Pass
  [`--strict-cache`](/cache#fail-on-a-stale-recording) to fail on stale
  recordings instead of calling a model. A step that was never recorded, or
  whose recording has a gap, still
  [runs live](/cache#fail-on-a-stale-recording).
- **Deterministic checks.** `expect(locator)` runs locally with no model.
  With the built-in agent, `agent.assert`, `agent.waitFor`, and
  `agent.extract` always call the model.
