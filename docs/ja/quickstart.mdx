## コーディングエージェントでセットアップする

アプリのディレクトリで Claude Code、Codex、Cursor などのコーディングエージェントを開き、
次のプロンプトを貼り付けてください。

<SetupPrompt>

<Prompt description={setupPrompt} children={setupPrompt} actions={["copy", "cursor"]} />

</SetupPrompt>

エージェントが [e2e スキル](/coding-agents) をインストールします。
以降は「購入手続きのテストを追加してください」などと依頼するだけで、追加のセットアップは不要です。

<Note>
Node.js 24.8 以降を使ってください。Node.js 22 を使う場合は 22.22.3 以降が必要です。
Web テストには [Bun](/reference/cli#bun) 1.4.3 以降も使えます。Windows では WSL 内で実行してください。
モバイルテストには、iOS シミュレーターのランタイムを含む Xcode、またはエミュレーターを含む Android SDK も必要です。
</Note>

## 手動でセットアップする

### 最初のテストを実行する

<Steps>
  <Step title="テストプロジェクトを作成する">
  アプリのディレクトリで次を実行します。

  <CodeGroup>
  ```bash npm
  npx e2e init
  ```

  ```bash pnpm
  pnpm dlx e2e init
  ```

  ```bash bun
  bunx e2e init
  ```
  </CodeGroup>

  **Web (Playwright)** または **Mobile (iOS/Android)** を選びます。
  次にサブスクリプションかモデルプロバイダーを選びます。AI を使わないテストなら **None** を選んでください。
  ウィザードが設定ファイルとサンプルテストを作成し、依存関係を追加します。
  コーディングエージェントのセットアップも選べます。既存のファイルは保持されます。

  <Tabs>
    <Tab title="Web">
    アプリの開発サーバーを `http://localhost:3000` で起動します。
    別のアドレスを使う場合は `e2e.config.ts` に設定してください。
    [e2e に起動を任せる](/web#starting-your-app) こともできます。

    <Accordion title="Web 用の設定とテストの例">
    この例では Vercel AI Gateway を使います。ウィザードを使う場合は、選んだプロバイダーに合わせて設定されます。

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';
import { gateway } from 'ai';

export default {
  agents: { default: { model: gateway('openai/gpt-6-luna-fast') } },
  targets: [{ engine: web(), app: { url: 'http://localhost:3000' } }],
} satisfies E2EConfig;
```

```ts title="tests/example.e2e.ts"
import { test } from '@e2e-dev/web';
import { expect } from 'e2e';

test('app opens', async ({ app, browser }) => {
  await app.open('/');
  await expect(browser.locator('body')).toBeVisible();
});
```
    </Accordion>
    </Tab>
    <Tab title="モバイル">
    `npx e2e doctor` で実行環境を確認します。
    ウィザードは macOS では iOS、それ以外では Android を選びます。
    サンプルテストは端末の設定アプリを開きます。

    <Accordion title="iOS 用の設定とテストの例">
    この例では Vercel AI Gateway を使います。Android を選ぶと、ウィザードは
    `platform: 'android'` と `app: { bundleId: 'com.android.settings' }` を設定します。

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { mobile } from '@e2e-dev/mobile';
import { gateway } from 'ai';

export default {
  agents: { default: { model: gateway('openai/gpt-6-luna-fast') } },
  targets: [{ name: 'ios', engine: mobile({ platform: 'ios' }), app: { bundleId: 'Settings' } }],
  workers: 1,
} satisfies E2EConfig;
```

```ts title="tests/example.e2e.ts"
import { test } from '@e2e-dev/mobile';
import { expect } from 'e2e';

test('Settings opens', async ({ app, screen }) => {
  await app.open();
  await expect(screen.getByRole('button', 'General')).toBeVisible();
});
```
    </Accordion>

    自分のアプリをテストするには、[モバイル](/mobile) を参照してください。
    </Tab>
  </Tabs>
  </Step>
  <Step title="サンプルを実行する">
  <CodeGroup>
  ```bash npm
  npx e2e run
  ```

  ```bash pnpm
  pnpm exec e2e run
  ```

  ```bash bun
  bunx e2e run
  ```
  </CodeGroup>

  e2e がブラウザをダウンロードするか、シミュレーターまたはエミュレーターを起動します。
  アプリが開くことを確認し、結果を表示します。
  このサンプルはモデルを呼び出さないため、サインインも API キーも不要です。
  </Step>
</Steps>

  <Tab title="サブスクリプション">

### エージェントステップを追加する

`agent.act` の呼び出しごとに、[1 つの結果に絞ったゴール](/core-concepts#goals) を指定し、その後で結果を確認します。
次のサンプルを、アプリの操作手順に合わせて書き換えてください。

<Tabs>
  <Tab title="Web">
```ts title="tests/agent.e2e.ts"
import { test } from '@e2e-dev/web';
import { expect } from 'e2e';

test('a visitor signs up for a trial', async ({ app, agent, screen }) => {
  await app.open('/');

  await agent.act('sign up for a free trial as {name} with email {email}', {
    params: { name: 'Ada Lovelace', email: 'ada@example.test' },
  });

  await agent.assert('the welcome screen greets Ada by name');
  await expect(screen.getByRole('status')).toContainText('trial');
});
```
  </Tab>
  <Tab title="モバイル (iOS)">
```ts title="tests/agent.e2e.ts"
import { test } from '@e2e-dev/mobile';
import { expect } from 'e2e';

test('the agent opens General', async ({ agent, app, device }) => {
  await app.open();
  await agent.act('open {section} settings', { params: { section: 'General' } });

  await agent.assert('the General settings screen is showing');
  await expect(device.locator('role=navigation-bar id=General')).toBeVisible();
});
```

  `app.open()` はアプリを起動し直します。省略すると、前のテストが終了したときのデバイスの状態を引き継ぎます。
  `device.locator` には [agent-device のセレクター](/mobile#the-device-fixture) を指定します。
  </Tab>
</Tabs>

`params` の値がゴール内のプレースホルダーに入ります。
`agent.assert` は画面の内容を判定し、`expect` は値が期待どおりかを正確に確認します。

<CodeGroup>
```bash npm
npx e2e run tests/agent.e2e.ts
```

```bash pnpm
pnpm exec e2e run tests/agent.e2e.ts
```

```bash bun
bunx e2e run tests/agent.e2e.ts
```
</CodeGroup>

ウィザードで **None** を選んだ場合は、先に [モデルを追加](/models) してください。
Web テストの動きを画面で見るには `--headed` を追加してください。
キャッシュされた操作をリプレイせずにモデルを呼び出すには `--no-cache` を追加してください。

### プロジェクトを設定する

設定は `e2e.config.ts` に記述します。`init` の後によく変更する項目は次のとおりです。

| 目的 | 設定項目 | 参照先 |
| --- | --- | --- |
| テスト対象のアプリを指定する | `app.url`、モバイルでは `app.bundleId` | [テスト対象のアプリ](/reference/config#the-app-under-test) |
| テスト実行時にアプリを起動する | `app.command` | [アプリを起動する](/web#starting-your-app) |
| モデルを使う | `agents.default.model` | [モデル](/models) |
| 複数のブラウザやデバイスで実行する | `targets` にそれぞれ `name` 付きで追加 | [targets](/reference/config#targets) |
| タイムアウトまでの時間を延ばす | `timeout`、`actionTimeout`、`assertionTimeout` | [timeout](/reference/config#timeout) |
| 失敗したテストをリトライする | `retries`、CI では `1` | [retries](/reference/config#retries) |
| テストを並列実行する | `workers`、CI では `1` | [workers](/reference/config#workers) |
| テストファイルを指定する | `tests` | [tests](/reference/config#tests) |
| トレースと動画を保存する | `trace`、`video` | [記録](/reference/config#recording) |
| JUnit レポートを出力する | `reporters: ['list', 'junit']` | [reporters](/reference/config#reporters) |
| サインイン情報や API キーを渡す | `credentials`、`secrets` | [認証](/authentication) |
| CI でリプレイキャッシュを書き込む | `cache: 'read-write'` | [キャッシュ](/cache) |

<Accordion title="よく使う設定の例">
```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';
import { gateway } from 'ai';

const app = {
  url: process.env.APP_URL ?? 'http://localhost:3000',
  command: { executable: 'npm', args: ['run', 'dev'], reuseExisting: true },
};

export default {
  agents: { default: { model: gateway('openai/gpt-6-luna-fast') } },
  targets: [
    { name: 'chromium', engine: web({ viewport: { width: 1440, height: 900 } }), app },
    { name: 'firefox', engine: web({ browser: 'firefox' }), app },
  ],
  timeout: 180_000,
  workers: 4,
  reporters: ['list', 'junit'],
  video: 'retain-on-failure',
} satisfies E2EConfig;
```

`--target firefox` で実行すると、そのターゲットだけが対象になります。
同じ `command` を使うターゲットは、1 つのサーバープロセスを共有します。
</Accordion>
