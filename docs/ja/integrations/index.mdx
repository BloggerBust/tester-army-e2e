公式連携パッケージは、エンジンのプロバイダーインターフェースを通じて、
ホスト型サービスの `browser` または `device` をターゲットに提供します。
変更するのは、設定内のターゲットの `browser` または `device` だけです。

## 連携パッケージのないサービスを使う

他のサービスには、プロジェクト内に小さなプロバイダーを作成します。
Web エンジンには [`BrowserProvider`](/browser#hosted-browsers)、
モバイルエンジンには [`DeviceProvider`](/mobile#hosted-devices) を実装します。

GitHub Actions、Expo Workflows、Norrix などの CI サービスで e2e を実行するには、
[継続的インテグレーション](/ci) を参照してください。
