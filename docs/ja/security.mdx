e2e は、利用者が書いたコードを信頼し、アプリが表示するものはすべて信頼できない入力として扱います。アプリのコンテンツが、モデルにツールや認証情報を与えたり、予算を増やしたりすることはできません。

## シークレットをモデルから守る仕組み

`Secret` は、平文の値を取り出す手段のないハンドルです。モデルに見えるのは名前と用途だけです。モデルが入力を要求すると、ランナーがフィールドを確認し、値を直接入力します。

既知のシークレットの値はすべて、モデルのテキスト入力、レポート、コンソール出力、`.txt`、`.csv`、`.json`、`.html`、`.htm` のダウンロード内で `<secret:name>` に置き換わります。

## それでも漏れる可能性のある情報

秘匿は文字列の一致によって行い、スクリーンショットでは機密フィールドだけをマスキングします。

- **モデルに渡すものを含むスクリーンショット。** 通常の入力欄に入力した汎用シークレットや、機密フィールドの外にアプリが表示した値は画像に写り、モデルプロバイダーに渡ります。本番のシークレットではなく、テスト用の認証情報を使ってください。
- **動画とダウンロード。** 動画は一切マスキングされません。秘匿対象のテキストファイル以外のダウンロードは、提供されたまま保存されます。テストでパスワードを入力した場合は、共有前に確認してください。
- **`command.log`。** アプリの標準出力と標準エラー出力をそのまま保存します。アプリの出力にシークレットを含めないでください。
- **変形された値。** キーの末尾 4 文字や base64 表現は秘匿されません。シークレット自体ではなく、操作の結果をアサートしてください。
- **シークレットとして入力していない値。** 秘匿されるのは設定済みのシークレットの値だけです。ログインによって Cookie に設定された値は対象になりません。
- **リクエストの認証情報。** `headers` は、アプリのオリジンまたは列挙したオリジン宛てに始まるすべてのリクエストに付きます。第三者のページが開始したリクエストにも付き、そのリダイレクト先がどのオリジンでも保持されます。`basicAuth` はそれらのオリジンからの `401` に応答します。WebKit では、それらのオリジンのいずれかがデフォルトポートを使うか IPv6 ホストを持つ場合、どのオリジンからの `401` にも応答します。
- **コミットされた記録。** キャッシュエントリーは、シークレットの入力を除き、入力値をそのまま保存します。署名されておらず、利用者の権限で再生されるため、テストコードと同じようにレビューしてください。

すべてのケースは[秘匿の対象外](/reference/security#where-redaction-stops)に記載しています。

## モデルが見る情報と実行する操作

モデルには、指示、アクセシビリティツリーとしての画面、機密情報を秘匿した URL、テスト内のそれまでのステップの記録が渡されます。モデルが要求するか、ステップに `vision` が設定されていると、マスキング済みのスクリーンショットも渡されます。

モデルはツールを通してだけ操作します。ランナーは実行前に各呼び出しを閉じたスキーマで検証し、モデルのテキストをコードとして評価しません。組み込みツールは未宣言のキーを拒否します。ただしフィールドがないツールはキーを捨てて実行します。プロジェクトツールは自身の `defineTool` スキーマに従います。`file:` への移動など、ルールに違反する呼び出しは `POLICY_DENIED` で失敗します。オリジンの許可リストはありません。エージェントはアプリから別のサイトへ移動し、そこでステップのシークレットを使えます。

macOS と Windows では、Chromium は OS のサンドボックスを有効にして起動します。エージェントが到達したページでのレンダラーの脆弱性悪用を封じ込める助けになります。Linux ではオプトインです。[`chromiumSandbox`](/reference/web#chromiumsandbox) を参照してください。

## 利用者の権限で実行されるもの

テスト、設定、エンジン、ツール、レポーター、ストア、シークレットプロバイダー、アプリコマンドは、サンドボックスなしで利用者の OS 権限で動きます。信頼できないプルリクエストのコードは、シークレットや書き込みトークンを持たない外部サンドボックスで実行してください。

## コンピューターの外に送られるもの

実行は、モデルプロバイダー、テスト対象のアプリ、そして無効化していなければ `eu.i.posthog.com` の[テレメトリー](/telemetry)に接続します。クラッシュレポートは送信しません。ターミナル上の CLI コマンドは、1 日に最大 1 回、`registry.npmjs.org` で新しいリリースを確認します。`e2e feedback` は `--allow-outdated` がない限り報告のたびに確認し、`e2e upgrade` はプロジェクトに記載された e2e パッケージのバージョンを取得します。Kernel、Expo Simulators、Limrun、smol などの連携は、それぞれ独自の接続先を追加します。他の接続先とともに[外向きの接続](/reference/security#outbound-connections)に記載しています。

## 脆弱性を報告する

[GitHub セキュリティアドバイザリー](https://github.com/e2e-inc/e2e/security/advisories/new)、または security@e2e.com 宛てのメールで非公開の報告を送ってください。[セキュリティポリシー](https://github.com/e2e-inc/e2e/blob/main/SECURITY.md)に、応答時間とサポート対象バージョンを記載しています。
