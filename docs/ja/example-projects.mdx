各サンプルは独立した挨拶アプリで、3 つのロケーターテストと 2 つのエージェントテストを含みます。
エージェントテストの一方は名前に対する挨拶を取得し、もう一方は名前が空の場合のエラーを確認します。
どのサンプルも npm で公開された e2e パッケージをインストールします。

## サンプルを実行する

各プロジェクトの README に従い、インストール、ビルド、実行を行います。
設定とテストはアプリのそばにあります。
ネイティブ、Flutter、.NET MAUI のプロジェクトでは `e2e/` フォルダーにあります。

ロケーターテストにモデルは不要です。
エージェントテストは Vercel AI Gateway を使い、`AI_GATEWAY_API_KEY` が未設定ならスキップされます。

`create-next-app` でサンプルから新しい Next.js アプリを作るには、[Next.js](/frameworks/nextjs#start-a-new-app) を参照してください。
