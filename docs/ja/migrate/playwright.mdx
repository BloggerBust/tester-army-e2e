## 設定を移す

<Note>[クイックスタート](/quickstart)で e2e をインストールし、モデルを設定してください。</Note>

`testDir`、`baseURL`、`use`、`webServer`、`projects` などの Playwright のキーは、代わりに使う e2e のキーを示すメッセージで失敗します。すべてのキーは[設定リファレンス](/reference/config)にあります。

| Playwright | e2e |
| --- | --- |
| `use.baseURL`, `webServer` | ターゲットの `app: { url, command }`。[アプリの起動](/web#starting-your-app)を参照 |
| `webServer.reuseExistingServer` | `app.command: { reuseExisting: true }`。CI では無視 |
| `projects` | `targets`。それぞれ独立したエンジンインスタンス |
| `testDir`, `testMatch`, `testIgnore` | プロジェクトルートからの glob を指定する `tests`。先頭の `!` で除外 |
| `retries`, `workers`, `timeout` | 同名。[デフォルト値は一部異なります](#defaults-that-differ)。`workers` は整数 |
| `expect.timeout`, `use.actionTimeout`, `globalTimeout` | `assertionTimeout`、`actionTimeout`、`maxDuration`。`maxDuration` の計測はアプリの起動時ではなくテスト開始時から |
| `maxFailures`, `use.headless: false` | CLI の `--max-failures <n>` と `--headed` |
| `reporter`, `outputDir` | `reporters: ['list', 'junit', htmlReporter()]`。`htmlReporter` は `@e2e-dev/html-reporter` から。`dot`、`json`、`markdown` も利用可能。出力先は `output`、デフォルトは `.e2e` |
| `use.viewport`, `locale`, `timezoneId`, `colorScheme`, `reducedMotion`, `userAgent`, `testIdAttribute` | `web({ ... })` 内の同名キー |
| `use.browserName`, `httpCredentials`, `extraHTTPHeaders` | `web({ browser, basicAuth, headers })`。`basicAuth` と `headers` はアプリのオリジンだけに適用。[`credentialOrigins`](/reference/web#credentialorigins) で追加可能 |
| `chromium.connectOverCDP(url)` | `web({ connect: { cdpEndpoint: () => url } })`。chromium のみ |
| `use.trace`, `use.video` | 設定、ターゲット、テストの `trace` と `video` にモードを指定。動画サイズは `web({ screencast: { size } })` |
| `use.permissions` | ターゲットの `app.permissions`。[ブラウザの権限を許可する](/web#granting-browser-permissions)を参照 |
| `setup` プロジェクトからの `use.storageState` | `test.setup` 内で `session.save(name)`、テストには `{ session }`。[認証](/authentication)を参照 |
| 固定値の `use.storageState: { cookies }` | フィクスチャ内で `browser.setCookies(cookies)` |

## spec を 1 つ書き換える

ウィザードや購入手続きなど、手順がよく変わるフローから始めてください。安定した Playwright テストは、そのまま残せます。

```ts title="Playwright"
import { test, expect } from '@playwright/test';

test('checkout', async ({ page }) => {
  await page.goto('/cart');
  await page.getByRole('button', { name: 'Checkout' }).click();
  await page.getByLabel('Card number').fill('4242424242424242');
  await page.getByLabel('Expiry').fill('12/30');
  await page.getByLabel('CVC').fill('123');
  await page.getByRole('button', { name: 'Pay' }).click();
  await expect(page.getByRole('heading')).toHaveText('Order confirmed');
});
```

```ts title="e2e"
import { test } from '@e2e-dev/web';
import { expect } from 'e2e';

test('checkout', async ({ app, agent, screen }) => {
  await app.open('/cart');
  await agent.act('pay with the test card 4242 4242 4242 4242, expiry 12/30, CVC 123');
  await expect(screen.getByRole('heading')).toHaveText('Order confirmed');
});
```

エージェントが購入手続きの各操作を行い、フォームの変更にも対応します。各 `page.getBy*` を `screen.getBy*` に置き換え、完全に決定論的なテストとして保つこともできます。

## ページオブジェクトを移す

ページオブジェクトには `screen` と `browser` を渡します。`screen` はクエリとアクション用、`browser` はキーボード、マウス、CSS セレクター、`evaluate` 用です。ページオブジェクトはフィクスチャとして提供してください。

```ts title="tests/page-models/account-page.ts"
import type { Locator, Screen } from 'e2e';
import type { Browser } from '@e2e-dev/web';

export class AccountPage {
  readonly accountName: Locator;

  constructor(
    readonly screen: Screen,
    readonly browser: Browser,
  ) {
    this.accountName = screen.getByTestId('account-name');
  }

  async filterByNote(note: string) {
    await this.screen.getByRole('button', 'Filter').click();
    await this.screen.getByRole('button', 'Note').click();
    await this.browser.keyboard.type(note);
  }
}
```

```ts title="tests/fixtures.ts"
import { test as base } from '@e2e-dev/web';
import { AccountPage } from './page-models/account-page.ts';

export const test = base.extend<{ accountPage: AccountPage }>({
  accountPage: async ({ screen, browser }, use) => {
    await use(new AccountPage(screen, browser));
  },
});
```

`browser` を指定するフィクスチャは、それを使うすべてのテストを Web 専用にします。[移植性を保つ](/page-object-model#keep-it-portable)を参照してください。各試行は新しいコンテキストで始まるため、フックから `newPage()` と `page.close()` を削除します。

## e2e にまだない機能

「実装予定」はロードマップに載っています。「未対応」は日程が未定です。「実装予定なし」は意図的に含めていません。代替手段を使うか、そのテストを Playwright に残してください。

### 実装予定

<AccordionGroup>
<Accordion title="ロケーターとアクション">

| Playwright | 現在使える方法 |
| --- | --- |
| `locator.locator(selector)`, `locator.and()`, `filter({ visible })` | `'.card >> .close'` のような単一の `browser.locator` セレクター、またはスコープ内の `screen` クエリ |
| `locator.evaluate()`, `expect(locator).toHaveClass()`, `toHaveCSS()`, `dispatchEvent()` | `browser.evaluate(fn, selector)`。`expect(browser).toHaveClass(locator, cls)` |
| `selectOption([...])`, `hover({ position })` | 複数選択には `browser.evaluate`。`boundingBox()` と `browser.mouse` |

</Accordion>
<Accordion title="アサーション">

| Playwright | 現在使える方法 |
| --- | --- |
| `expect(fn).toPass()`, `expect.poll(fn, { intervals })` | `expect.poll(async () => { ...; return true }).toBe(true)` |
| `toBeEmpty()`, `toBeInViewport()` | フォームには `toHaveValue('')`、ほかの要素には `toHaveText('')`。`boundingBox()` を `expect.poll` で確認 |

## 意図的に異なる点

- 文字列は、大文字・小文字を区別してテキスト全体と照合します。Playwright の `getByRole` の名前、`getByLabel`、`getByPlaceholder`、`getByText` は、大文字・小文字を区別しない部分一致です。部分一致には `{ exact: false }` または `RegExp` を渡してください。[クエリ](/reference/screen#queries)を参照してください。

  ```ts
  // <button>Save changes</button>, <label>Email address <input></label>
  screen.getByRole('button', 'Save');                  // no match
  screen.getByRole('button', { name: 'Save', exact: false });    // matches
  screen.getByRole('button', 'save changes');          // no match, case differs
  screen.getByLabel('Email');                                    // no match
  ```
- 読み取るのは描画済みテキストです。`textContent()`、`toHaveText`、`toContainText` は `innerText` と同じ内容を読み、非表示のテキストは除外し、`text-transform` を適用します。[ロケーターの読み取り](/reference/screen#locator-reads)を参照してください。
- `toHaveRole` は `getByRole` と同じロール名を使います。`paragraph`、`generic` など、そこにないロールは型エラーになり、`img` は `image` と読みます。比較するのはツリー上のロールで、`contenteditable` エディターは `textbox` です。
- ロケーターは厳密です。複数一致した場合、アクション、読み取り、肯定形のマッチャーは `LOCATOR_AMBIGUOUS` になります。Playwright の `page.click(selector)` や `isVisible()` は最初の一致を使います。`filter` や `first()` で絞り込んでください。
- `.not.toBeChecked()` はボタンや見出しでも成功します。コントロールの種類が変わったら失敗するように、ロールで対象を探してください。
- セッションは 1 回の実行内だけ有効です。`test.setup` が名前付きで状態を保存し、`{ session }` が復元します。ファイルは暗号化し、クリーンアップ時に削除するため、再利用する `.auth/user.json` はありません。
- テストには生の `Page` を渡しません。その上の操作は記録も秘匿もマスキングもされないためです。`surfaceOf(engine)` はテストコード向けではなく、[カスタムエグゼキューター](/executors#driving-the-page-yourself)向けです。

## デフォルト値の違い

| 設定 | Playwright | e2e |
| --- | --- | --- |
| テストのタイムアウト | 30 秒 | 120 秒、`timeout` |
| アクションのタイムアウト | なし | 30 秒、`actionTimeout` |
