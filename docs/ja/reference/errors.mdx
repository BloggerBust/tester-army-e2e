ランナーのすべてのエラーには、分類とコードがあります。分類は終了コードを決め、コードは原因を表します。モデルがこれらを選ぶことはありません。`e2e login`、`e2e logout`、`e2e models` は例外です。[終了コード](#exit-codes)を参照してください。

```ts title="tests/upgrade.e2e.ts"
import { isAgentError, test } from 'e2e';

test('upgrade to Pro', async ({ agent }) => {
  try {
    await agent.act('upgrade the workspace to Pro');
  } catch (error) {
    if (isAgentError(error) && error.code === 'STEP_TIMEOUT') {
      // the step ran out of time; the message carries the last judgment
      console.error(error.category, error.details);
    }
    throw error;
  }
});
```

## リファレンス

### 終了コード

| 分類 | 終了コード |
| --- | ---: |
| test | 1 |
| configuration | 2 |
| infrastructure | 3 |
| internal | 4 |
| interrupted | 130 |

- 複数の種類の結果が混在する実行では、優先順位が最も高いコードを使います。優先順位は `130 > 4 > 3 > 2 > 1 > 0` です。レポートには個々の結果をすべて残します。
- クリーンアップに失敗したテスト（必要な動画を確定できなかった、セッションを閉じられなかったなど）は、そのクリーンアップエラーのコードで終了します。通常は 3 です。
- セットアップのアサーション失敗はテスト失敗となり、依存するテストをスキップします。セットアップに必要なインフラがない場合は、configuration または infrastructure の分類を維持します。
- `internal` 分類と終了コード 4 は、ランナーの不変条件への違反のために予約されています。現時点で、公式コードがこの分類のエラーを発生させることはありません。
- `e2e login`、`e2e logout`、`e2e models` は、失敗時にコードを付けずメッセージを表示し、1 で終了します。サインインや選択画面をキャンセルした場合は 130 です。

| コード | 説明 |
| --- | --- |
| [エージェントのコード](#agent-codes) | `AgentError` の `code` |
| [ランナーのコード](#runner-codes) | 出力とレポート内の文字列コード |
| [テストコードのエラー](#test-code-errors) | テストコードから投げられるエラー |

### AgentError

`AgentError` はランナーが分類したエージェントの失敗を表し、`e2e` からエクスポートされます。

```ts
/** Runner-classified agent failure. */
export class AgentError extends Error {
  /** Closed union, assigned by the runner, never taken from model text. */
  readonly code: AgentErrorCode;
  /** The error class in the table above; it sets the exit code. */
  readonly category: 'test' | 'configuration' | 'infrastructure' | 'internal' | 'interrupted';
  readonly retryable: boolean;
  /** Structured facts: locator, expected, observed, match count, wait time. */
  readonly details: ErrorDetails | undefined;
  /** Sanitized, bounded prose; the same value as `message`. */
  readonly explanation: string;
  /** Artifact path, present only when evidence was captured and permitted. */
  readonly screenshot?: string;
  /** True when this failure reports a blocked step, not a product failure. */
  readonly blocked: boolean;
}
```

<Note>
テストファイルは独自のモジュール領域に読み込まれるため、`instanceof AgentError` が false になることがあります。このページ冒頭の例のように、`e2e` の `isAgentError` を使い、`code` で分岐してください。
</Note>
