Uma integração oficial é um pacote que dá a um alvo o `browser` ou o `device`
dele a partir de um serviço hospedado, pela interface de provedor da engine.
Só o `browser` ou o `device` do alvo na configuração muda.

## Use um serviço sem integração

Para qualquer outro serviço, escreva um pequeno provedor no seu projeto: um
[`BrowserProvider`](/browser#hosted-browsers) para a engine web ou um
[`DeviceProvider`](/mobile#hosted-devices) para a engine mobile.

Para rodar o e2e em um serviço de CI como GitHub Actions, Expo Workflows ou
Norrix, veja [Integração contínua](/ci).
