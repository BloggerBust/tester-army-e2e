## अपने कोडिंग एजेंट से सेट अप करें

यह प्रॉम्प्ट अपने ऐप की डायरेक्टरी में Claude Code, Codex, Cursor या किसी
दूसरे कोडिंग एजेंट में पेस्ट करें:

<SetupPrompt>

<Prompt description={setupPrompt} children={setupPrompt} actions={["copy", "cursor"]} />

</SetupPrompt>

एजेंट [e2e स्किल](/coding-agents) इंस्टॉल करता है, इसलिए बाद के प्रॉम्प्ट,
जैसे "चेकआउट के लिए एक टेस्ट जोड़ें", के लिए और सेटअप की ज़रूरत नहीं पड़ती।

<Note>
Node.js 24.8 या उससे नया वर्ज़न इस्तेमाल करें (Node.js 22 पर 22.22.3 या उससे नया), या वेब टेस्ट के लिए [Bun](/reference/cli#bun) 1.4.3 या उससे नया। Windows पर WSL के अंदर चलाएँ। मोबाइल टेस्ट के लिए
iOS सिम्युलेटर रनटाइम के साथ Xcode, या एम्युलेटर के साथ Android SDK भी चाहिए।
</Note>

### एजेंट चरण जोड़ें

`agent.act` को हर कॉल में एक [एटॉमिक लक्ष्य](/core-concepts#goals) दें, फिर
नतीजा जाँचें। उदाहरण को अपने ऐप के किसी फ़्लो के हिसाब से ढालें:

<Tabs>
  <Tab title="वेब">
```ts title="tests/agent.e2e.ts"
import { test } from '@e2e-dev/web';
import { expect } from 'e2e';

test('a visitor signs up for a trial', async ({ app, agent, screen }) => {
  await app.open('/');

  await agent.act('sign up for a free trial as {name} with email {email}', {
    params: { name: 'Ada Lovelace', email: 'ada@example.test' },
  });

  await agent.assert('the welcome screen greets Ada by name');
  await expect(screen.getByRole('status')).toContainText('trial');
});
```
  </Tab>
  <Tab title="मोबाइल (iOS)">
```ts title="tests/agent.e2e.ts"
import { test } from '@e2e-dev/mobile';
import { expect } from 'e2e';

test('the agent opens General', async ({ agent, app, device }) => {
  await app.open();
  await agent.act('open {section} settings', { params: { section: 'General' } });

  await agent.assert('the General settings screen is showing');
  await expect(device.locator('role=navigation-bar id=General')).toBeVisible();
});
```

  `app.open()` ऐप को नए सिरे से लॉन्च करता है। इसके बिना टेस्ट वहीं से शुरू
  होता है जहाँ पिछले टेस्ट ने डिवाइस को छोड़ा था। `device.locator`
  [agent-device सेलेक्टर](/mobile#the-device-fixture) लेता है।
  </Tab>
</Tabs>

`params` लक्ष्य के प्लेसहोल्डर भरते हैं। `agent.assert` स्क्रीन का आकलन करता है।
`expect` एक सटीक वैल्यू जाँचता है।

<CodeGroup>
```bash npm
npx e2e run tests/agent.e2e.ts
```

```bash pnpm
pnpm exec e2e run tests/agent.e2e.ts
```

```bash bun
bunx e2e run tests/agent.e2e.ts
```
</CodeGroup>

अगर आपने विज़ार्ड में **None** चुना था, तो पहले [एक मॉडल जोड़ें](/models)।
वेब टेस्ट को चलते हुए देखने के लिए `--headed` जोड़ें। कैश किए गए एक्शन रीप्ले
करने के बजाय मॉडल को कॉल करने के लिए `--no-cache` जोड़ें।

### प्रोजेक्ट कॉन्फ़िगर करें

विकल्प `e2e.config.ts` में रहते हैं। ज़्यादातर प्रोजेक्ट `init` के बाद ये
विकल्प बदलते हैं:

| क्या करना है | क्या सेट करें | देखें |
| --- | --- | --- |
| अपने ऐप की ओर इशारा करना | `app.url`, या मोबाइल पर `app.bundleId` | [टेस्ट होने वाला ऐप](/reference/config#the-app-under-test) |
| रन के साथ ऐप शुरू करना | `app.command` | [अपना ऐप शुरू करना](/web#starting-your-app) |
| मॉडल इस्तेमाल करना | `agents.default.model` | [मॉडल](/models) |
| कई ब्राउज़र या डिवाइस पर टेस्ट करना | हर एक के लिए एक `targets` एंट्री, `name` के साथ | [targets](/reference/config#targets) |
| टेस्ट को ज़्यादा समय देना | `timeout`, `actionTimeout`, `assertionTimeout` | [timeout](/reference/config#timeout) |
| फ़ेल हुए टेस्ट रीट्राई करना | `retries`, CI में `1` | [retries](/reference/config#retries) |
| टेस्ट पैरेलल में चलाना | `workers`, CI में `1` | [workers](/reference/config#workers) |
| टेस्ट फ़ाइलें चुनना | `tests` | [tests](/reference/config#tests) |
| ट्रेस और वीडियो रखना | `trace`, `video` | [रिकॉर्डिंग](/reference/config#recording) |
| JUnit रिपोर्ट लिखना | `reporters: ['list', 'junit']` | [reporters](/reference/config#reporters) |
| साइन इन करना और API कुंजियाँ देना | `credentials`, `secrets` | [ऑथेंटिकेशन](/authentication) |
| CI में रीप्ले कैश लिखना | `cache: 'read-write'` | [कैशिंग](/cache) |

<Accordion title="आम विकल्पों वाले कॉन्फ़िग का उदाहरण">
```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';
import { gateway } from 'ai';

const app = {
  url: process.env.APP_URL ?? 'http://localhost:3000',
  command: { executable: 'npm', args: ['run', 'dev'], reuseExisting: true },
};

export default {
  agents: { default: { model: gateway('openai/gpt-6-luna-fast') } },
  targets: [
    { name: 'chromium', engine: web({ viewport: { width: 1440, height: 900 } }), app },
    { name: 'firefox', engine: web({ browser: 'firefox' }), app },
  ],
  timeout: 180_000,
  workers: 4,
  reporters: ['list', 'junit'],
  video: 'retain-on-failure',
} satisfies E2EConfig;
```

`--target firefox` एक टारगेट चलाता है। जो टारगेट एक ही `command` साझा करते
हैं, वे एक ही सर्वर प्रोसेस साझा करते हैं।
</Accordion>
