## अपने कोडिंग एजेंट से सेट अप करें

अपने ऐप की डायरेक्टरी में Claude Code, Codex, Cursor या कोई भी कोडिंग एजेंट
खोलें और यह प्रॉम्प्ट पेस्ट कर दें:

<SetupPrompt>

<Prompt description={setupPrompt} children={setupPrompt} actions={["copy", "cursor"]} />

</SetupPrompt>

एजेंट [e2e स्किल](/coding-agents) इंस्टॉल कर देता है। इसके बाद "चेकआउट के
लिए एक टेस्ट जोड़ें" जैसे प्रॉम्प्ट के लिए कोई और सेटअप नहीं करना पड़ता।

<Note>
Node.js 24.8 या उससे नया इस्तेमाल करें (Node.js 22 पर 22.22.3 या उससे नया)। वेब
टेस्ट के लिए Node.js की जगह [Bun](/reference/cli#bun) 1.4.3 या उससे नया भी
चलेगा। Windows पर WSL के अंदर चलाएँ। मोबाइल टेस्ट के लिए साथ में iOS
सिम्युलेटर रनटाइम वाला Xcode, या एम्युलेटर वाला Android SDK भी चाहिए।
</Note>

### एजेंट स्टेप जोड़ें

`agent.act` की हर कॉल में एक ही [एटॉमिक लक्ष्य](/core-concepts#goals) दें,
फिर नतीजा चेक करें। इस उदाहरण को अपने ऐप के किसी फ़्लो पर ढाल लें:

<Tabs>
  <Tab title="वेब">
```ts title="tests/agent.e2e.ts"
import { test } from '@e2e-dev/web';
import { expect } from 'e2e';

test('a visitor signs up for a trial', async ({ app, agent, screen }) => {
  await app.open('/');

  await agent.act('sign up for a free trial as {name} with email {email}', {
    params: { name: 'Ada Lovelace', email: 'ada@example.test' },
  });

  await agent.assert('the welcome screen greets Ada by name');
  await expect(screen.getByRole('status')).toContainText('trial');
});
```
  </Tab>
  <Tab title="मोबाइल (iOS)">
```ts title="tests/agent.e2e.ts"
import { test } from '@e2e-dev/mobile';
import { expect } from 'e2e';

test('the agent opens General', async ({ agent, app, device }) => {
  await app.open();
  await agent.act('open {section} settings', { params: { section: 'General' } });

  await agent.assert('the General settings screen is showing');
  await expect(device.locator('role=navigation-bar id=General')).toBeVisible();
});
```

  `app.open()` ऐप को नए सिरे से लॉन्च करता है। यह न हो, तो टेस्ट वहीं से
  शुरू होता है जहाँ पिछला टेस्ट डिवाइस को छोड़कर गया था। `device.locator`
  [agent-device सेलेक्टर](/mobile#the-device-fixture) लेता है।
  </Tab>
</Tabs>

`params` लक्ष्य के प्लेसहोल्डर भरते हैं। `agent.assert` स्क्रीन को परखता है।
`expect` एक सटीक वैल्यू चेक करता है।

<CodeGroup>
```bash npm
npx e2e run tests/agent.e2e.ts
```

```bash pnpm
pnpm exec e2e run tests/agent.e2e.ts
```

```bash bun
bunx e2e run tests/agent.e2e.ts
```
</CodeGroup>

अगर विज़ार्ड में आपने **None** चुना था, तो पहले [एक मॉडल जोड़ें](/models)।
वेब टेस्ट चलते हुए देखना है तो `--headed` लगाएँ। कैश किए हुए एक्शन रीप्ले
करने की जगह मॉडल को कॉल करवाना है तो `--no-cache` लगाएँ।

### प्रोजेक्ट कॉन्फ़िगर करें

ऑप्शन `e2e.config.ts` में होते हैं। `init` के बाद ज़्यादातर प्रोजेक्ट ये
ऑप्शन बदलते हैं:

| क्या करना है | क्या सेट करें | देखें |
| --- | --- | --- |
| टेस्ट को अपने ऐप पर लगाना | `app.url`, मोबाइल पर `app.bundleId` | [टेस्ट होने वाला ऐप](/reference/config#the-app-under-test) |
| रन के साथ ऐप भी शुरू करना | `app.command` | [अपना ऐप शुरू करना](/web#starting-your-app) |
| मॉडल इस्तेमाल करना | `agents.default.model` | [मॉडल](/models) |
| कई ब्राउज़र या डिवाइस पर टेस्ट करना | हर एक के लिए `targets` में एक एंट्री, `name` के साथ | [targets](/reference/config#targets) |
| टेस्ट को ज़्यादा समय देना | `timeout`, `actionTimeout`, `assertionTimeout` | [timeout](/reference/config#timeout) |
| फ़ेल हुए टेस्ट रीट्राई करना | `retries`, CI में `1` | [retries](/reference/config#retries) |
| टेस्ट पैरेलल में चलाना | `workers`, CI में `1` | [workers](/reference/config#workers) |
| कौन-सी टेस्ट फ़ाइलें चलें, यह चुनना | `tests` | [tests](/reference/config#tests) |
| ट्रेस और वीडियो सेव रखना | `trace`, `video` | [रिकॉर्डिंग](/reference/config#recording) |
| JUnit रिपोर्ट लिखना | `reporters: ['list', 'junit']` | [reporters](/reference/config#reporters) |
| साइन इन करना और API keys देना | `credentials`, `secrets` | [ऑथेंटिकेशन](/authentication) |
| CI में रीप्ले कैश लिखना | `cache: 'read-write'` | [कैशिंग](/cache) |

<Accordion title="आम ऑप्शन वाले कॉन्फ़िग का उदाहरण">
```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';
import { gateway } from 'ai';

const app = {
  url: process.env.APP_URL ?? 'http://localhost:3000',
  command: { executable: 'npm', args: ['run', 'dev'], reuseExisting: true },
};

export default {
  agents: { default: { model: gateway('openai/gpt-6-luna-fast') } },
  targets: [
    { name: 'chromium', engine: web({ viewport: { width: 1440, height: 900 } }), app },
    { name: 'firefox', engine: web({ browser: 'firefox' }), app },
  ],
  timeout: 180_000,
  workers: 4,
  reporters: ['list', 'junit'],
  video: 'retain-on-failure',
} satisfies E2EConfig;
```

`--target firefox` सिर्फ़ एक टारगेट चलाता है। जिन टारगेट का `command` एक ही
है, वे एक ही सर्वर प्रोसेस शेयर करते हैं।
</Accordion>
