## Nastavení s kódovacím agentem

Vlož tento prompt do Claude Code, Codexu, Cursoru nebo jiného kódovacího
agenta v adresáři své aplikace:

<SetupPrompt>

<Prompt description={setupPrompt} children={setupPrompt} actions={["copy", "cursor"]} />

</SetupPrompt>

Agent nainstaluje [skill e2e](/coding-agents), takže další prompty, například
„přidej test pro checkout“, už žádné další nastavení nepotřebují.

<Note>
Použij Node.js 24.8 nebo novější (na Node.js 22 verzi 22.22.3 nebo novější), případně pro webové testy [Bun](/reference/cli#bun) 1.4.3 nebo novější. Ve Windows spouštěj e2e uvnitř WSL. Mobilní testy navíc
potřebují Xcode s runtimem simulátoru iOS, nebo Android SDK s emulátorem.
</Note>

## Ruční nastavení

### Spusť svůj první test

<Steps>
  <Step title="Vytvoř testovací projekt">
  V adresáři své aplikace spusť:

  <CodeGroup>
  ```bash npm
  npx e2e init
  ```

  ```bash pnpm
  pnpm dlx e2e init
  ```

  ```bash bun
  bunx e2e init
  ```
  </CodeGroup>

  Zvol **Web (Playwright)** nebo **Mobile (iOS/Android)**, potom předplatné,
  poskytovatele modelu, nebo **None** pro testy bez AI. Průvodce vytvoří
  konfiguraci a ukázkový test, přidá závislosti a nabídne nastavení tvého
  kódovacího agenta. Existující soubory ponechá.

  <Tabs>
    <Tab title="Web">
    Spusť vývojový server své aplikace na `http://localhost:3000`, nebo nastav
    jeho adresu v `e2e.config.ts`. Můžeš ho také [nechat spustit přes e2e](/web#starting-your-app).

    <Accordion title="Ukázková webová konfigurace a test">
    Tato konfigurace používá Vercel AI Gateway. Průvodce nastaví poskytovatele, kterého zvolíš.

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';
import { gateway } from 'ai';

export default {
  agents: { default: { model: gateway('openai/gpt-6-luna-fast') } },
  targets: [{ engine: web(), app: { url: 'http://localhost:3000' } }],
} satisfies E2EConfig;
```

```ts title="tests/example.e2e.ts"
import { test } from '@e2e-dev/web';
import { expect } from 'e2e';

test('app opens', async ({ app, browser }) => {
  await app.open('/');
  await expect(browser.locator('body')).toBeVisible();
});
```
    </Accordion>
    </Tab>
    <Tab title="Mobilní">
    Spusť `npx e2e doctor` a zkontroluj své nastavení. Průvodce zvolí na macOS
    iOS a jinde Android. Ukázka otevře aplikaci Nastavení.

    <Accordion title="Ukázková konfigurace a test pro iOS">
    Tato konfigurace používá Vercel AI Gateway. Pro Android průvodce nastaví
    `platform: 'android'` a `app: { bundleId: 'com.android.settings' }`.

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { mobile } from '@e2e-dev/mobile';
import { gateway } from 'ai';

export default {
  agents: { default: { model: gateway('openai/gpt-6-luna-fast') } },
  targets: [{ name: 'ios', engine: mobile({ platform: 'ios' }), app: { bundleId: 'Settings' } }],
  workers: 1,
} satisfies E2EConfig;
```

```ts title="tests/example.e2e.ts"
import { test } from '@e2e-dev/mobile';
import { expect } from 'e2e';

test('Settings opens', async ({ app, screen }) => {
  await app.open();
  await expect(screen.getByRole('button', 'General')).toBeVisible();
});
```
    </Accordion>

    Jak použít vlastní aplikaci, najdeš v části [Mobilní aplikace](/mobile).
    </Tab>
  </Tabs>
  </Step>

  ```bash pnpm
  pnpm exec e2e run
  ```

### Přidej agentní krok

Dej `agent.act` při každém volání jeden [atomický úkol](/core-concepts#goals)
a potom zkontroluj výsledek. Uprav ukázku podle toku ve své aplikaci:

<Tabs>
  <Tab title="Web">
```ts title="tests/agent.e2e.ts"
import { test } from '@e2e-dev/web';
import { expect } from 'e2e';

test('a visitor signs up for a trial', async ({ app, agent, screen }) => {
  await app.open('/');

  await agent.act('sign up for a free trial as {name} with email {email}', {
    params: { name: 'Ada Lovelace', email: 'ada@example.test' },
  });

  await agent.assert('the welcome screen greets Ada by name');
  await expect(screen.getByRole('status')).toContainText('trial');
});
```
  </Tab>
  <Tab title="Mobilní (iOS)">
```ts title="tests/agent.e2e.ts"
import { test } from '@e2e-dev/mobile';
import { expect } from 'e2e';

test('the agent opens General', async ({ agent, app, device }) => {
  await app.open();
  await agent.act('open {section} settings', { params: { section: 'General' } });

  await agent.assert('the General settings screen is showing');
  await expect(device.locator('role=navigation-bar id=General')).toBeVisible();
});
```

  `app.open()` spustí aplikaci načisto. Bez něj test začíná tam, kde
  zařízení nechal předchozí test. `device.locator` přijímá
  [selektory agent-device](/mobile#the-device-fixture).
  </Tab>
</Tabs>

`params` doplní zástupné symboly v úkolu. `agent.assert` posuzuje obrazovku.
`expect` kontroluje přesnou hodnotu.

<CodeGroup>
```bash npm
npx e2e run tests/agent.e2e.ts
```

```bash pnpm
pnpm exec e2e run tests/agent.e2e.ts
```

```bash bun
bunx e2e run tests/agent.e2e.ts
```
</CodeGroup>

Pokud jsi v průvodci zvolil **None**, nejdřív [přidej model](/models). Přidej
`--headed`, pokud chceš webový test sledovat. Přidej `--no-cache`, pokud chceš
místo přehrávání akcí z cache volat model.

### Nakonfiguruj projekt

Možnosti najdeš v `e2e.config.ts`. Většina projektů po `init` mění
tyto:

| Chceš | Nastav | Viz |
| --- | --- | --- |
| nasměrovat testy na svou aplikaci | `app.url`, na mobilu `app.bundleId` | [Testovaná aplikace](/reference/config#the-app-under-test) |
| spouštět aplikaci spolu s během testů | `app.command` | [Spuštění aplikace](/web#starting-your-app) |
| použít model | `agents.default.model` | [Modely](/models) |
| testovat více prohlížečů nebo zařízení | pro každý jednu položku `targets` s `name` | [targets](/reference/config#targets) |
| dát testům více času | `timeout`, `actionTimeout`, `assertionTimeout` | [timeout](/reference/config#timeout) |
| opakovat neúspěšné testy | `retries`, v CI `1` | [retries](/reference/config#retries) |
| spouštět testy paralelně | `workers`, v CI `1` | [workers](/reference/config#workers) |
| vybrat testovací soubory | `tests` | [tests](/reference/config#tests) |
| uchovávat trace a videa | `trace`, `video` | [Nahrávání](/reference/config#recording) |
| vytvářet report JUnit | `reporters: ['list', 'junit']` | [reporters](/reference/config#reporters) |
| přihlašovat se a předávat API klíče | `credentials`, `secrets` | [Autentizace](/authentication) |
| zapisovat replay cache v CI | `cache: 'read-write'` | [Cache](/cache) |

<Accordion title="Ukázková konfigurace s běžnými možnostmi">
```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';
import { gateway } from 'ai';

const app = {
  url: process.env.APP_URL ?? 'http://localhost:3000',
  command: { executable: 'npm', args: ['run', 'dev'], reuseExisting: true },
};

export default {
  agents: { default: { model: gateway('openai/gpt-6-luna-fast') } },
  targets: [
    { name: 'chromium', engine: web({ viewport: { width: 1440, height: 900 } }), app },
    { name: 'firefox', engine: web({ browser: 'firefox' }), app },
  ],
  timeout: 180_000,
  workers: 4,
  reporters: ['list', 'junit'],
  video: 'retain-on-failure',
} satisfies E2EConfig;
```

`--target firefox` spustí jeden cíl. Cíle se stejným `command` sdílejí
jeden serverový proces.
</Accordion>
