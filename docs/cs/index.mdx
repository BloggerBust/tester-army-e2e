e2e je open source framework pro testování webových a mobilních aplikací.
Test může používat přesné [lokátory](/core-concepts#locators) a
[aserce](/reference/expect#locator-matchers), [úkoly](/core-concepts#goals)
v přirozeném jazyce, které splní agent, nebo obojí v jednom testu.

```ts title="tests/checkout.e2e.ts"
import { test, expect } from 'e2e';

test('a member upgrades to Pro', async ({ app, agent, screen }) => {
  await app.open('/settings/billing');

  await agent.act('upgrade the workspace to the Pro plan');
  await agent.assert('the invoice preview shows a prorated amount');

  await expect(screen.getByRole('status')).toContainText('Pro');
});
```

## Proč e2e

- **Méně času nad testy.** Místo skriptu se selektory a čekáním napíšeš
  úkol. Když se UI změní, agent se přizpůsobí, takže opravuješ méně testů.
- **Levné běhy.** e2e zaznamená krok `agent.act`, když následná kontrola
  projde. Další běh ho [přehraje](/cache) bez volání modelu a předá řízení
  zpět agentovi, když se aplikace změnila. S vestavěným agentem `assert`,
  `waitFor` a `extract` model volají vždy.

## Jak to funguje

- **Cíle.** Každý test běží jednou na každém cíli, třeba v Chromiu nebo na
  simulátoru iPhonu. [Webový engine](/web) ovládá prohlížeče přes
  Playwright. [Mobilní engine](/mobile) ovládá simulátory iOS a emulátory
  Androidu přes agent-device. Můžeš také
  [napsat vlastní](/writing-an-engine).
- **Kroky agenta.** `agent.act` splní úkol. `agent.assert`,
  `agent.waitFor` a `agent.extract` posuzují obrazovku. Použij vlastní
  [předplatné](/subscriptions), [API klíč nebo lokální model](/models). Testy
  bez kroků agenta žádný model nepotřebují.
- **Reporty.** Runner [maskuje registrované tajné klíče](/security) ve vstupu
  pro model. Zaznamenává kroky, selhání a artefakty do
  [reportu](/debugging), který si přečteš ty nebo tvůj kódovací agent.
